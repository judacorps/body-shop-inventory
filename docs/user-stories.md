# User Stories

1. Como técnico, quiero tomar foto del número de unidad para no escribirlo manualmente.
2. Como técnico, quiero tomar foto del odómetro para que se detecte el mileage automáticamente.
3. Como técnico, quiero ver y corregir datos detectados cuando OCR falle para evitar errores.
4. Como supervisor, quiero ver advertencia cuando mileage disminuya vs histórico para identificar anomalías.
5. Como auditor, quiero conservar fotos originales asociadas al registro para trazabilidad.
6. Como operador de flota, quiero conocer el último mileage de una unidad al momento de capturar para validación rápida.
7. Como usuario de taller, quiero que la app funcione offline para no depender de conectividad.
